# 🎀 Salma cumple 1 añito 🎈

Invitación web interactiva y animada para el primer añito de **Salma**, con temática del payaso **Plim Plim** en tonos rosa pastel.

## ✨ Características

- 💗 Pantalla de bienvenida con marco de corazón y globos que vuelan al abrir
- 🎈 Animaciones modernas: glassmorphism, orbes de fondo, gradientes y microinteracciones
- ⏳ Cuenta regresiva en vivo al gran día
- 🗓️ Timeline con fecha, hora, lugar y dress code
- 🗺️ Botón para ver la ubicación en el mapa
- 💬 Confirmación de asistencia por WhatsApp con mensaje listo
- 🎵 Música de fondo
- 📱 Diseño responsive mobile-first

## 📅 El evento

- **Fecha:** Viernes 18 de diciembre de 2026, 4:00 p. m.
- **Lugar:** Salón de eventos Tu Fiesta · Cra 42h #84b-107 · Plaza 85 · Barranquilla

## 🚀 Ver en local

```bash
npx http-server -p 8099 -c-1 .
```

Luego abre `http://127.0.0.1:8099`.

## 🛠️ Tecnología

HTML, CSS y JavaScript puro (sin frameworks). Animaciones con Web Animations API e IntersectionObserver.
